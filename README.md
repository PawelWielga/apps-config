# apps-config

Public runtime configuration for Paweł Wielga's applications.

## Rules

- Store only public, non-secret configuration here.
- Never commit API keys, signing material, passwords, access tokens, or other credentials.
- Keep each application under its own directory.
- Prefer backward-compatible changes so older released app versions can keep working.
